0. Core Rules & Mathematical Formulas

Tangent Slope (mt): mt = dy/dx = f'(x)
Slope of Perpendicular Normal (mn): mn = -1 / mt
Tangent Line Equation: y - y0 = mt(x - x0)
Normal Line Equation: y - y0 = mn(x - x0)

2. Five Advanced STEM Exam-Style Solved Examples

Example 1 (High-Level Implicit & Normal): Find the equation of the normal line to the curve x² + y² - 4x - 6y - 12 = 0 at the point (7, 5).
Step 1: Implicit differentiation: 2x + 2y(dy/dx) - 4 - 6(dy/dx) = 0. At point (7,5), substituting gives dy/dx = mt = -3/4.
Step 2: Normal slope mn = -1 / mt = 4/3. Equation: y - 5 = (4/3)(x - 7) ⇒ 4x - 3y - 13 = 0.
Example 2 (Parameter Optimization in Cubics): Find the value of k if the tangent line to y = kx³ - 3x² + 4x at x = 1 is perpendicular to the line x + 2y = 5.
Step 1: Reference line slope is -1/2, so the required perpendicular tangent slope is mt = 2.
Step 2: Find derivative: dy/dx = 3kx² - 6x + 4. At x = 1: 3k(1)² - 6(1) + 4 = 2 ⇒ 3k - 2 = 2 ⇒ 3k = 4 ⇒ k = 4/3.
Example 3 (Points with Horizontal/Vertical Tangents): Find all points on the curve y = 2x³ - 9x² + 12x where the tangent line is horizontal.
Step 1: Set slope mt = dy/dx = 6x² - 18x + 12 = 0.
Step 2: Simplify to x² - 3x + 2 = 0 ⇒ (x - 1)(x - 2) = 0 ⇒ x = 1 or x = 2. Corresponding points are (1, 5) and (2, 4).
Example 4 (Parallel Tangents to External Lines): Find the equations of the tangents to the curve y = x³ - 3x that are parallel to the line 9x - y = 5.
Step 1: Parallel slope means mt = 9. Set dy/dx = 3x² - 3 = 9 ⇒ 3x² = 12 ⇒ x² = 4 ⇒ x = ±2.
Step 2: At x = 2, point is (2, 2) and equation is y - 2 = 9(x - 2). At x = -2, point is (-2, -2) and equation is y + 2 = 9(x + 2).
Example 5 (Exponential & Chain Rule Challenge): Find the equation of the normal line to y = x · e^(x-1) at x = 1.
Step 1: Product rule: dy/dx = e^(x-1) + x · e^(x-1). At x = 1, mt = e^0 + 1(e^0) = 1 + 1 = 2.
Step 2: Normal slope mn = -1/2. Point is (1, 1). Equation: y - 1 = -1/2(x - 1) ⇒ x + 2y - 3 = 0.
