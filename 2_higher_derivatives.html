1. Core Laws: Higher Derivatives, Tangent & Normal Perpendicularity

  • First Derivative (Slope of Tangent): m_t = dy/dx = f'(x)
  • Second Derivative (Rate of Change of Slope): m_2 = d²y/dx² = f''(x)
  • Perpendicularity Condition: m_t * m_n = -1 => m_n = -1 / m_t
  • Equations: Tangent: y - y_0 = m_t(x - x_0) | Normal: y - y_0 = m_n(x - x_0)

3. Five STEM-Level Solved Examples

Example 1 (Second Derivative): If y = x^4 - 5x^3 + 2, find d²y/dx².
Solution: dy/dx = 4x^3 - 15x^2 => d²y/dx² = 12x^2 - 30x.
Example 2 (Higher Derivative Value): If f(x) = sin(2x), find f''(π/4).
Solution: f'(x) = 2cos(2x) => f''(x) = -4sin(2x). At x = π/4, f''(π/4) = -4sin(π/2) = -4.
Example 3 (Tangent & Perpendicular Normal Slopes): Find the slope of the normal line to y = x^3 - 3x at x = 2.
Solution: m_t = 3(2)^2 - 3 = 9. Since normal is perpendicular, m_n = -1/9.
Example 4 (Implicit Higher Derivative): Given x^2 + y^2 = 25, find dy/dx at (3, 4).
Solution: 2x + 2y(dy/dx) = 0 => dy/dx = -x/y = -3/4.
Example 5 (Third Derivative): Find d^3/dx^3 (e^(2x)).
Solution: First derivative = 2e^(2x), second = 4e^(2x), third = 8e^(2x).
