📚 Core Examples (AP-Level)

Example 1: Find the second derivative of \(y = x^4 - 5x^3 + 2x - 7\).

Example 2: Given \(y = e^{2x} \sin(x)\), find \(y''\).

Example 3: Find the equation of the tangent line to the curve \(y = x^3 - 3x + 1\) at \(x = 2\).

Example 4: Find the equation of the normal line to the curve \(y = \sqrt{x^2 + 5}\) at \(x = 2\).

Example 5: If \(f(x) = \ln(3x)\), find the third derivative \(f'''(x)\).

📝 Class Work Exercises

1. Find \(\frac{d^2 y}{dx^2}\) if \(y = \cos(3x)\).
2. Find the slope of the normal line to \(y = x^3 - 2x\) at \(x = 1\).
3. If \(f(x) = x e^x\), find \(f''(1)\).
4. Find the point on the curve \(y = x^2\) where the tangent line is parallel to the line \(4x - y = 1\).
5. Find the second derivative of \(y = \ln(\sin x)\).

🏠 Homework Assignment

1. Find \(\frac{d^3 y}{dx^3}\) for \(y = 2x^5 - 4x^3 + 7\).
2. Find the equation of the tangent line to \(y = \frac{8}{4+x^2}\) at \(x = 2\).
3. If \(x^2 + y^2 = 25\), find \(\frac{d^2 y}{dx^2}\) at point \((3, 4)\).
4. Find the value of \(k\) for which \(y = e^{kx}\) satisfies \(y'' - 3y' - 4y = 0\).
5. Find the derivative of order 100 of \(y = \sin(x)\).
