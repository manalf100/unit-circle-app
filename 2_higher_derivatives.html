0. Core Rules & Mathematical Formulas

• Tangent Slope: m_t = dy/dx = f'(x)
• Slope of Perpendicular Normal: m_n = -1 / m_t
• Tangent Line Equation: y - y_0 = m_t(x - x_0)
• Normal Line Equation: y - y_0 = m_n(x - x_0)

2. Five Exam-Style Solved Examples (Step-by-Step)

Example 1: Find the equation of the normal line to $x^2 + y^2 = 25$ at $(3, 4)$.
Step 1: Implicit differentiation: $2x + 2y \frac{dy}{dx} = 0 \Rightarrow \frac{dy}{dx} = -\frac{x}{y}$. At $(3,4)$, $m_t = -\frac{3}{4}$.
Step 2: Normal slope $m_n = -\frac{1}{m_t} = \frac{4}{3}$. Equation: $y - 4 = \frac{4}{3}(x - 3)$.
Example 2: Find $k$ if the tangent to $y = kx^3 - 4x$ at $x = 1$ is perpendicular to $2x + 6y = 11$.
Step 1: Reference line slope is $-\frac{2}{6} = -\frac{1}{3}$, so required tangent slope $m_t = 3$.
Step 2: $\frac{dy}{dx} = 3kx^2 - 4$. Substitute $x = 1$: $3k(1)^2 - 4 = 3 \Rightarrow 3k = 7 \Rightarrow k = \frac{7}{3}$.
Example 3: Find points on $y = x^3 - 3x^2$ where the tangent line is horizontal.
Step 1: Set $m_t = 0 \Rightarrow \frac{dy}{dx} = 3x^2 - 6x = 0$.
Step 2: Solve for $x$: $3x(x - 2) = 0 \Rightarrow x = 0$ or $x = 2$. Corresponding points are $(0,0)$ and $(2,-4)$.
Example 4: Find the tangent to $y = x^3 - 3x$ parallel to $9x - y = 5$.
Step 1: Parallel line slope is $9$, so $m_t = 9$. Set $3x^2 - 3 = 9 \Rightarrow x^2 = 4 \Rightarrow x = \pm 2$.
Step 2: Formulate tangent equations at points $(2, 2)$ and $(-2, -2)$ using $m = 9$.
Example 5: Find the slope of the normal line to $y = x e^x$ at $x = 0$.
Step 1: Product rule: $\frac{dy}{dx} = e^x + x e^x$. At $x = 0$, $m_t = e^0 + 0 = 1$.
Step 2: Normal slope $m_n = -\frac{1}{1} = -1$.
