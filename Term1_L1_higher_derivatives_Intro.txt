    <!-- 1. Rules & Concepts -->
    <div class="box">
        <h2>1. Key Rules & Concepts</h2>
        <p><strong>First Derivative (\( f'(x) \)):</strong> Represents the instantaneous rate of change and the slope of the tangent line to the curve at any point.</p>
        <p><strong>Second Derivative (\( f''(x) \)):</strong> Represents the rate of change of the slope, used to determine concavity.</p>
        <p><strong>Power Rule:</strong> If \( f(x) = x^n \), then \( f'(x) = n x^{n-1} \).</p>
    </div>

    <!-- 3. Five Step-by-Step Examples -->
    <h2>3. Step-by-Step Examples</h2>
    
    <div class="example-box">
        <strong>Example 1:</strong> Find the derivative of \( f(x) = 4x^3 - 2x + 5 \).<br>
        <em>Step-by-step:</em> Apply power rule to each term. \( f'(x) = 4(3x^2) - 2(1) + 0 = 12x^2 - 2 \).
    </div>
    <div class="example-box">
        <strong>Example 2:</strong> Find the second derivative of \( f(x) = 5x^4 - 3x^2 \).<br>
        <em>Step-by-step:</em> First derivative = \( 20x^3 - 6x \). Second derivative = \( 60x^2 - 6 \).
    </div>
    <div class="example-box">
        <strong>Example 3:</strong> Find the slope of the tangent line to \( f(x) = x^2 \) at \( x = 3 \).<br>
        <em>Step-by-step:</em> Derivative is \( f'(x) = 2x \). Substitute \( x = 3 \): Slope = \( 2(3) = 6 \).
    </div>
    <div class="example-box">
        <strong>Example 4:</strong> Find the critical points of \( f(x) = x^3 - 3x \).<br>
        <em>Step-by-step:</em> Set \( f'(x) = 3x^2 - 3 = 0 \). Solving gives \( x = 1 \) and \( x = -1 \).
    </div>
    <div class="example-box">
        <strong>Example 5:</strong> Evaluate the rate of change for \( f(t) = t^3 - 6t^2 + 9t \) at \( t = 2 \).<br>
        <em>Step-by-step:</em> \( f'(t) = 3t^2 - 12t + 9 \). At \( t = 2 \): \( 3(4) - 12(2) + 9 = 12 - 24 + 9 = -3 \).
    </div>

<script>
    function updateSimulator(val) {
        let slope = (2 * parseFloat(val)).toFixed(1);
        document.getElementById('sliderValueText').innerText = "At x = " + val + " | Slope (Tangent) = " + slope;
    }

    function checkMCQ(qNum, correctAns) {
        let radios = document.getElementsByName('q' + qNum);
        let selected = null;
        for (let r of radios) {
            if (r.checked) { selected = r.value; break; }
        }
        let fb = document.getElementById('q' + qNum + '-fb');
        if (!selected) {
            fb.style.color = "orange";
            fb.innerText = "⚠️ Please select an option!";
            return;
        }
        if (selected === correctAns) {
            fb.style.color = "green";
            fb.innerText = "✅ Correct!";
        } else {
            fb.style.color = "red";
            fb.innerText = "❌ Incorrect. Try again!";
        }
    }
</script>
